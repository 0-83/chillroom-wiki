### Могилы
После смерти игрок оставляет за собой могилу в виде его головы, её можно открыть нажав ПКМ или забрать Shift + ПКМ.
Список своих могил вы можете посмотреть прописав команду `/grave list`.
### Patpat
Установите клиентский [мод patpat](https://modrinth.com/plugin/patpat) и можете наслаждать поглаживанием всего что движется.
### Система виртуального счета АР
- `/deposit` - положить на счет, приписав `all`, кладёт все "ары" из инвентаря.
- `/with` - снять со счета.
- `/pay` - перевести другому игроку.
- `/baltop` - Топ по балансу сервера.
### CustomDiscs SVC
| Команда                               | Что делает                                                |
| ------------------------------------- | --------------------------------------------------------- |
| `/cd create local имя.mp3 "Название"` | Превратить диск в руке в кастомный (из локального файла)  |
| `/cd create remote "URL" "Название"`  | То же, но со стримом с YouTube/SoundCloud                 |
| `/cd distance <радиус>`               | Задать радиус слышимости проигрывателя (кликаешь по нему) |
1. Положи mp3 в `plugins/CustomDiscs/musicdata` (или скачай через `/cd download`).
2. Возьми в **главную руку** обычный музыкальный диск.
3. `/cd create local файл.mp3 "Название"`.
4. Вставь диск в проигрыватель — играет.
