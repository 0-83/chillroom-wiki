# Донат
## Подписка — 350 ₽/мес

**Возможности:**
- **Кастомные эффекты вокруг игрока** — визуальные частицы, окружающие персонажа.
- **Доступ к /bazaar из любой точки мира** — торговля без визита на базар.
Подписка активируется на 30 дней с момента оплаты.
## Кастомка — от 1500 ₽
**Ограничения по характеристикам:**
- Значения не превышают **20% от ванильно добываемых**. Например, у Остроты V (урон +3) кастомная версия может давать не более **+3,6 урона** (то есть +20% сверх ванильного значения).
- Оружие создаётся под игрока, характеристики фиксируются в момент выдачи.
**Способности — на ваш выбор.** Можно придумать любую механику. Примеры:

| Способность         | Описание                                                                        |     |
| ------------------- | ------------------------------------------------------------------------------- | --- |
| **Рывок**           | ПКМ активирует короткий рывок вперёд с неуязвимостью на 0,5 с. Перезарядка 8 с. |     |
| **Хил от воды**     | Восстановление 1 ❤ каждые 2 с, пока игрок стоит в воде.                         |     |
| **Прыжок-телепорт** | ПКМ телепортирует на 5 блоков в направлении взгляда, если путь свободен.        |     |
| **Кровопийца**      | Восстанавливает 0,5 ❤ за каждое попадание по противнику.                        |     |

**Подача заявки:** тикет с описанием предмета — тип оружия, желаемые характеристики (в пределах +20%) и способность с точной механикой. Заявка рассматривается администрацией; после одобрения предмет выдаётся игроку.

**Примечание:** администрация оставляет за собой право отклонить способность, нарушающую баланс, и предложить альтернативу.
