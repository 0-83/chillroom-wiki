### CoreProtect
**CoreProtect** — логирование всех действий игроков (блоки, вещи) с возможностью отката гриферства.
- `/co i` — режим инспектора: ЛКМ по блоку покажет, кто его поставил/сломал; ПКМ по сундуку — кто открывал.
- `/co near` — посмотреть последние изменения рядом.
### BreweryX
**BreweryX** — варка алкогольных напитков с выдержкой в бочках и эффектами опьянения.
- `/brew` — информация о напитке в руке (качество, название)
- Основной процесс — через котёл (варка), бочку (выдержка) и коптильню.
### AxGraves
**AxGraves** — После смерти игрок оставляет за собой могилу в виде его головы, её можно открыть нажав ПКМ или забрать Shift + ПКМ.
- `/graves` — меню со списком своих могил.
### VoxyServerSide
**VoxyServerSide** — серверная поддержка мода Voxy (бесконечная прогрузка чанков у клиента).
### PlayerParticles
**PlayerParticles** — косметические частицы вокруг игроков.
- `/pp` — открыть меню выбора частиц и стилей
**Доступно для VIP пользователей.**
### DiamondEconomy
**DiamondEconomy** — простая экономика сервера на алмазах.
- `/deposit` - положить на счет, приписав `all`, кладёт все "ары" из инвентаря.
- `/with` - снять со счета, приписав `all`, снимаете все "ары" с баланса.
- `/pay` - перевести другому игроку.
- `/baltop` - Топ по балансу сервера.
### BetterJails
**BetterJails** — jails-система: тюрьма для наказания вместо бана.
### PingWheel
**PingWheel** — серверная часть мода Ping Wheel (метки-пинги в мире).
### CustomDiscs
**CustomDiscs** — кастомные музыкальные пластинки (с клиентским модом).
- Возьми в **главную руку** обычный музыкальный диск.
- `/cd create local файл.mp3 "Название"`.
- Вставь диск в проигрыватель — играет.
  Важное примечание: ссылки на треки и треки игроки отправляют в дс-чат, после этого администрация добавляет их на сервер. 
### ImageFrame
**ImageFrame** — вывод реальных изображений на рамках и картах.
- `/if create <ссылка> [ширина] [высота]` — создать изображение (смотря на стену с рамками)
- `/if delete` — удалить своё изображение
- `/if list` — список изображений
### PatPat
**PatPat** — команда «погладить» игрока по голове (анимация).
### AnvilUnlocker
**AnvilUnlocker** — убирает ограничение «Слишком дорого» на наковальне.
### Shopkeepers
**Shopkeepers** — NPC-торговцы и витрины для магазинов.
- `/shopkeeper` — меню создания магазина (с сундуком в руке — свой магазин-витрина)
- ПКМ по торговцу — редактирование/пополнение.
### ArmorStandEditor
**ArmorStandEditor** — удобное редактирование стоек брони прямо в игре.
- ПКМ кремнём по стойке — поворот/смена позы
- ПКМ по воздуху — меню настроек стойки (поза, руки, размер, невидимость)
### SkinsRestorer
**SkinsRestorer** — восстановление скинов на офлайн-сервере.
- `/skin <ник>` — установить скин игрока
- `/skin url <ссылка>` — скин по ссылке
- `/skin update` — обновить скин
- `/skin clear` — сбросить
### GSit
**GSit** — возможность сидеть, лежать и ползти.
- `/sit` — сесть (также ПКМ по ступеньке/плите)
- `/lay` — лечь
- `/crawl` — ползти
### AxTrade
**AxTrade** — безопасный обмен предметами между игроками (GUI-обмен).
- `/trade <игрок>` — предложить обмен
### Emotecraft
**Emotecraft** — серверная часть мода эмоций/жестов.
### FastLeafDecay
**FastLeafDecay** — быстрое осыпание листвы после срубки дерева.
### CauldronConcrete / CauldronMud
**CauldronConcrete / CauldronMud** — добавляют механики получения бетона и грязи через котёл.
### Gardener's Dream
